# STORM CONNECT

Высокоскоростная система удалённого рабочего стола, многомониторного управления, передачи файлов и защищённой ретрансляции трафика экосистемы **STORM**.

## Ключевые возможности

- **Многомониторный захват DXGI + Delta-кодирование**: Захват экрана через Native DXGI Desktop Duplication с автоматическим переключением между отдельными мониторами и режимом «Все мониторы», плюс потайловое (`64x64`) delta-сжатие.
- **Сквозное шифрование (End-to-End)**: Обмен ключами **ECDH P-256**, вывод сессионных ключей через **HKDF-SHA256** и потоковое шифрование **AES-256-GCM** на всех каналах связи (LAN Direct, Direct IP, WSS Relay).
- **Умный выбор маршрута подключения**:
  - Автоматическое обнаружение устройств в локальной сети (**LAN Discovery** по UDP);
  - Прямое гигабитное TCP-соединение в локальной сети и по внешнему IP;
  - Резервный шифрованный **WSS-ретранслятор** с нулевым знанием содержимого (`StormConnect.Relay`) и UDP-сигнализацией для стабильной работы за NAT и корпоративными шлюзами.
- **Полный контроль ввода и системных команд**: Передача координат мыши по всему виртуальному рабочему столу, прокрутка, сочетания клавиш, быстрые действия (`Диспетчер задач`, `Блокировка ПК`, `Win+R`, `Alt+Tab`, снимок экрана).
- **Двусторонний буфер обмена и передача аудио**: Мгновенная синхронизация текста и изображений с защитой от эха и потоковая передача звука.
- **Двухпанельный файловый менеджер + Drag-and-Drop**: Просмотр дисков и папок удалённого устройства, загрузка и скачивание файлов потоками по 256 КБ с проверкой SHA-256, а также перетаскивание файлов прямо на окно удалённого экрана.
- **Адресная книга и Wake-on-LAN**: Хранение устройств по группам, быстрый запуск сессии и пробуждение спящих ПК по локальной сети (Magic Packet).
- **Гибкая безопасность**: Одноразовый PIN-код, настраиваемый пароль постоянного неконтролируемого доступа (DPAPI + PBKDF2-SHA256), интерактивное окно подтверждения с выбором прав (управление, буфер обмена, файлы, звук) и журнал аудита сессий.
- **Единый интерфейс экосистемы STORM**:
  - **11 языков** с автоматическим определением языка ОС и мгновенным переключением;
  - **9 тем оформления** (`MIDNIGHT`, `NIGHT`, `DARK`, `DAY`, `FANTASY`, `CYBERPUNK`, `WARHAMMER 40K`, `ELEMENTAL`, `STORM`);
  - **13 цветов акцента** и **10 шрифтов** с динамическим переключением без перезапуска;
  - Сворачивание в системный трей, автообновление и единый тёмный установщик с поддержкой стандартного и портативного режимов.
- **Нативный клиент Android (`APK`)**: Совместимый мобильный клиент с управлением касаниями и масштабированием щипком, переключением мониторов, скачиванием файлов в `/storage/emulated/0/STORM CONNECT/downloads`, интеграцией с Samsung Game Booster и динамическим переключением тем, акцентов, шрифтов и языков.

## Развёртывание собственного сервера-ретранслятора (`StormConnect.Relay`)

Проект включает готовый легковесный сервер ретрансляции и UDP-сигнализации в каталоге `src/StormConnect.Relay` и конфигурации в `deploy/`.

### Запуск через Docker Compose

```bash
cd deploy
docker compose up -d --build
```

По умолчанию сервер слушает:
- `7443/tcp` - WebSocket-ретранслятор (`/connect-relay`, `/ws`, `/session/{token}`) и `/health`;
- `7444/udp` - служба UDP-сигнализации.

### Подключение за Nginx (TLS / порт 443)

Добавьте фрагмент из `deploy/nginx-storm-connect-relay.conf` в конфигурацию вашего домена и укажите адрес `wss://<ваш-домен>/connect-relay` на вкладке **Сеть и ретранслятор** в приложении. Также в приложении доступен встроенный режим локального командного узла в один клик.

## Установка и сборка из исходников

### Готовые релизы

- **Установщик Windows (`*_Setup.exe`)** - установка в `C:\Program Files\STORM CONNECT` или портативный режим, настройка правил Брандмауэра Windows и ярлыков;
- **Портативный архив (`*.zip`)** - распакуйте в любую папку и запустите `STORM CONNECT.exe`;
- **Android (`*.apk`)** - установите на устройство Android (данные и загрузки хранятся в `/storage/emulated/0/STORM CONNECT`).

### Сборка на Windows

Требуются .NET SDK 10, JDK 21 и Android SDK (для сборки APK):

```powershell
.\build_all.ps1
```

Готовые подписанные файлы сохраняются в папку `Files/`.

## English Summary

**STORM CONNECT** is a high-performance multi-monitor remote desktop, encrypted file transfer, clipboard sync, audio streaming, Wake-on-LAN, and self-hosted WSS relay suite for Windows and Android within the STORM ecosystem. It uses clean-room open protocols (ECDH P-256 + HKDF-SHA256 + AES-256-GCM), supports 11 languages (OS default), 9 themes, 13 accents, 10 live fonts, close-to-tray behavior, portable mode, and includes a deployable Docker/systemd/Nginx relay server.
